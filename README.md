# Urban Clearance Planner

Browser-based planning tool for clearance operations in urban areas. Reads four ArcGIS layers (buildings, rubble, explosive ordnance, roads), scores every clearance task, and produces a dependency-aware schedule.

**Live app:** https://dbu1.github.io/urban-clearance-planner/

Sign in with your IMSMA Core portal credentials.

> **⚠ Operational disclaimer**
> This tool supports planning. It does not certify clearance, replace a technical survey, or substitute for EOD judgment. Weights and rates are defaults, not field-validated constants. Confirm anything involving explosive ordnance with qualified EOD personnel.
